# Titanic Survival Prediction

A machine learning web app that predicts whether a Titanic passenger would survive based on passenger details.

## 🚀 Live Demo

[Open the Titanic Survival Prediction App](https://titanic-survival-prediction-ag98m6znscptuqthe3bu7u.streamlit.app/)

## 📌 Features

- Predicts Titanic passenger survival
- Built with Python
- Uses Machine Learning
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## 📂 Project Files

- `app.py` — Streamlit application
- `titanic_model.pkl` — Trained machine learning model
- `feature_names.pkl` — Model feature names
- `requirements.txt` — Required Python libraries
